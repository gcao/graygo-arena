This plan adds verification only. It does not introduce network, persistence, browser, provider, or secret handling.

- Tests may cover only happy paths and miss edge cases that later providers can trigger.
- Property tests may be too broad and flaky if generated board sizes are not constrained.
- Future phases may accidentally import framework/provider code into the engine.

Required mitigations:
- Golden fixtures must be named and human-readable.
- Hypothesis strategies must constrain generated boards to valid symbols and practical sizes.

</threat_model>
