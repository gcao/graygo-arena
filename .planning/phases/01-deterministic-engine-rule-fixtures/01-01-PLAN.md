<threat_model>
This plan creates local deterministic engine code only. No network calls, browser code, provider credentials, persistence, or user input beyond tests are in scope.

Potential threats:
- Accepting invalid BoardKeys or coordinates could let later prompts/provider replies operate on stale or malformed state.
- Coupling engine primitives to FastAPI/Pydantic/SQLAlchemy would weaken the backend-authoritative pure-engine boundary.

Required mitigations:
- BoardKey and coordinate parsers must raise typed `ValueError` exceptions for malformed inputs.
- Engine modules created in this plan must not import `fastapi`, `pydantic`, `sqlalchemy`, `openai`, `anthropic`, or frontend/UI packages.
</threat_model>
